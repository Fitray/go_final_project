# Описание проекта

Проект является todo-листом, он позволяет создавать, удалять и изменять задачи, а также ставить дедлайны для их выполнения и задавать правила их повторения. Сервис был разработан в качестве дипломной работы для Яндекс Практикума.

# Выполненные задачи со звёздочкой

Были выполнены все задачи со звёздочкой:
1. Возможность определять извне порт при запуске сервера через переменную окружения TODO_PORT.
2. Возможность определять путь к файлу базы данных через переменную окружения TODO_DBFILE.
3. Вычисления следующих дат в случае недель и месяцев
4. Возможность выбрать задачи через строку поиска.
5. Аутентификация
6. Создание докер-образа

# Запуск сервиса локально

Для запуска нужно прописать только `go run cmd/main.go`, для проверки в браузере нужно перейти по `http://localhost:7540/`.

Вид .env файла:
TODO_PORT= # порт, на котором работает сервер
TODO_DBFILE= # путь к файлу БД. Следует указывать по пути: `data/название_бд.db`
TODO_PASSWORD= # пароль для доступа к серверу
TODO_JWT_SECRET= # секретный ключ для генерации JWT-токена

# Запуск тестов

Перед запуском тестов стоит запустить сервер локально и получить токен для получения доступа к серверу. Два варианта получения токена:
1. В Postman отправить POST запрос на `http://localhost:7540/api/signin` с Body в виде JSON:
{
    "password": "тут указанный в .env файле пароль (TODO_PASSWORD)"
}
2. Зайти в браузере на `http://localhost:7540/login.html`, ввести пароль из TODO_PASSWORD в .env файле, а затем при помощи консоли разработчика скопировать токен из cookie под названием token

Для запуска тестов в `tests/settings.go` стоит указать следующие параметры:

var Port = тут в виде числа должен быть указан порт из .env: TODO_PORT
var DBFile = "тут должен быть указан файл БД из .env: TODO_DBFILE"
var FullNextDate = true
var Search = true
var Token = "тут должен быть полученный ранее токен"

Далее нужно ввести команду: `go test -run ^TestApp$ ./tests`

# Сборка и запуск через Docker

1. Запускаем: `go mod tidy`
2. Собираем бинарный файл, используя команду: `CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o main cmd/main.go` или просто: `go build -o main cmd/main.go`
3. Для первого запуска используем команду: `docker compose up -d --build`, для последующих достаточно: `docker compose up -d`
4. Для остановки используем команду: `docker compose down`
